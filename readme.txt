A responsive Elementor widget for displaying WooCommerce product categories.

== Installation ==
1. Upload and activate the plugin.
2. Ensure Elementor and WooCommerce are active.
3. Edit a page with Elementor.
4. Search for "Mim Product Categories" and drag it onto the page.

== Features ==
* Custom title, subtitle, link text, URL, and arrow icon.
* Category quantity, ordering, level, and empty-category controls.
* Search and manually select one or more product categories.
* Product counts with a customizable suffix.
* Separate desktop, tablet, and mobile column controls.
* Responsive gaps, card padding, image sizing, colors, borders, and typography.
* Optional responsive carousel powered by Elementor's bundled Swiper library.
* Carousel controls for responsive slides, movement, autoplay, looping, direction, navigation, pagination, dragging, free mode, and auto height.
* Customizable carousel arrow icons, buttons, positioning, and pagination dots.
